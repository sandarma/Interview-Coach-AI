## Notes

During user testing, the application worked as expected, but users suggested several improvements to make the interview experience more natural and secure.

The feedback was grouped into three GitHub issues:

- Improve the onboarding experience with a welcome screen and dynamic topic picker.
- Make interview practice more realistic by serving random questions instead of a fixed sequence.
- Strengthen backend validation and protect the AI evaluation prompt against prompt injection attacks.
